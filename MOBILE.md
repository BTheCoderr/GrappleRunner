# GrappleRunner Mobile

GrappleRunner uses the current web game as the canonical gameplay implementation and wraps it with Capacitor for iOS and Android. This prevents the native build from drifting away from the tuned web physics and levels.

## iOS setup

```bash
npm install
npx cap add ios
npm run mobile:sync
npm run mobile:ios
```

Then build/run from Xcode on a physical iPhone. The native project generated by `cap add ios` should be committed once generated on macOS.

## Android setup

```bash
npm install
npx cap add android
npm run mobile:sync
npm run mobile:android
```

## Mobile QA gate

Before TestFlight: verify landscape/full-screen presentation, hold/release input, pause/resume, audio after backgrounding, haptics, all 10 levels, checkpoint respawns, saved progression, repeated restart, and cold launch.
