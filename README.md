# GrappleRunner

Mobile-first 3D grapple runner built directly in the browser.

## Core loop
Auto-run → hold to grapple → swing → release to launch → land → repeat.

## Current build
- Three.js 3D world
- Touch, mouse, and Spacebar controls
- Momentum-based grapple rope
- Rooftop collision and checkpoints
- Instant fall respawn
- Three escalating levels
- Speed-responsive camera
- Local best times
- Vercel-ready static deployment

## Product rule
Movement first. No shops, currencies, accounts, or feature clutter until the grapple/run loop is fun on a phone.
